# Rob Cawley

Musician in Dublin. I make records, and I build the instruments I use on them in Logic Pro, then give them away.

**Listen:** [Room Tone](https://robcawley.com/roomtone/), the new album · [Bandcamp](https://robcawley.bandcamp.com) · [robcawley.com](https://robcawley.com)

## Free tools for Logic Pro

All free and open source, for macOS (Apple Silicon and Intel). The plug-ins have ready-built downloads on each project's Releases page.

| | |
|---|---|
| **[NEON RIOT](https://github.com/robcawley/neon-riot)**<br>A heavy bass synthesizer: weight, grit, controlled chaos, and slow cinematic beds. 56 presets.<br>[▶ Preset showcase](https://youtu.be/XiO8jAuwAc4) | [![NEON RIOT preset showcase](https://raw.githubusercontent.com/robcawley/neon-riot/main/video.jpg)](https://youtu.be/XiO8jAuwAc4) |
| **[UNDERTOW](https://github.com/robcawley/undertow)**<br>An ambient space effect: drift, tape echo, a huge reverb with FREEZE, pulsing bands, and a sound-design page that keeps the space evolving. 92 presets, including pairs for NEON RIOT and a set for drums. | [![UNDERTOW](https://raw.githubusercontent.com/robcawley/undertow/main/screenshot.png)](https://github.com/robcawley/undertow) |
| **[BRUISER](https://github.com/robcawley/bruiser)**<br>A rock drummer that writes parts live: sections, fills, odd meters, 90 presets.<br>[▶ Preset showcase](https://youtu.be/yW3tiXdW_uU) | [![BRUISER preset showcase](https://raw.githubusercontent.com/robcawley/bruiser/main/video.jpg)](https://youtu.be/yW3tiXdW_uU) |
| **[ROB KIT](https://github.com/robcawley/rob-kit)**<br>A human-feeling drum instrument built from my own drum recordings. BRUISER plays it. | [![ROB KIT](https://raw.githubusercontent.com/robcawley/rob-kit/main/Design/ROB%20KIT%20-%20interface.png)](https://github.com/robcawley/rob-kit) |
| **[THE GREAT COMPOSER](https://github.com/robcawley/the-great-composer)**<br>Chords in, orchestral MIDI out. Step by step, for people with little music theory. Runs in the browser. | [![THE GREAT COMPOSER](https://raw.githubusercontent.com/robcawley/the-great-composer/main/screenshot.png)](https://github.com/robcawley/the-great-composer) |
| **[CLEARING](https://github.com/robcawley/clearing)**<br>An automatic mix EQ: it finds where tracks fight each other and carves the space. Optional MCP server so an assistant can drive it. | [![CLEARING](https://raw.githubusercontent.com/robcawley/clearing/main/screenshot.png)](https://github.com/robcawley/clearing) |

## Free music packs

Royalty-free music and loops for games and video, free on [itch.io](https://robcaw.itch.io) with a credit:

- [All this happened, more or less](https://robcaw.itch.io/night-chase-music): night-chase music, with a pixel-art chase that follows the beat
- [Cinematic Sci-Fi Music](https://robcaw.itch.io/cinematic-sci-fi-music): two long-form tracks
- [Darkeyes Ambient](https://robcaw.itch.io/darkeyes-ambient): dark ambient drones for exploration and dread
- [Wide-Eyes Cinematic](https://robcaw.itch.io/wide-eyes-cinematic)
- [Future Hip-Hop Drum + Bass Loops](https://robcaw.itch.io/future-hip-hop-drum-bass-loops)

The preview players on those pages are free to reuse: [itch-music-players](https://github.com/robcawley/itch-music-players).

If you make something with any of them, I'd love to hear it. Post it anywhere, and if you like, link back to my music.
